## 3. Крупные задачи, выполненные агентами (темы сессий)

Сводка по основному чату разработки voice matching (UUID `6331fa94-07e7-4a6f-b6cb-0a781664dcc9` и связанные):

- **Создание `voice-matching-service`** — FastAPI, ECAPA embeddings, POST `/voice-match`, GET `/health`, CORS для Next.js.
- **Подключение Admin AI Lab** — замена mock в `lib/admin-ai-voice-matching.ts` на реальный fetch.
- **Windows pip / SOCKS proxy** — `install-deps.ps1`, сброс proxy, PySocks.
- **Demucs** — vocal separation на AI reference, 10 s trim, CPU, fallback на mix.
- **CORS** — несколько итераций origins (3000–3002), middleware order, `0.0.0.0:8000`.
- **SpeechBrain k2 / lazy imports** — stubs без зависимости k2 и transformers.
- **Декодирование MP3** — torchcodec, ffmpeg, pydub chain.
- **Chunk averaging** — 5×2 s, RMS weights, `speaker_score`.
- **Scoring v2 → v4.2** — pitch/timbre/quality, vocal type penalties, stretch, caps, floor.
- **Gender-priority ranking** — `final_ranking_score`, hard partition female/male AI.
- **`MANUAL_DEMO_GENDER`**, **male prototype** `real_voice_1.wav`, **force demote** real_voice_1.
- **Таймауты 30 s**, partial responses.
- **Русский UI** в AI Lab — labels, vocal types, comparison sections.
- **Feature tags** — match/mismatch для лаборатории и debug.
- **Audio playback hook** — `hooks/use-lab-audio-playback.ts`.
- **Proxy hardening** в `main.py` и `run-server.ps1` для Hugging Face / httpx.
- **Документация бэкапа** (текущая задача).

## 4. Как возобновить работу в Cursor после переустановки

### Шаг 1 — Софт

1. Git, Node.js LTS, Python 3.10+, ffmpeg в PATH.
2. Cursor IDE.
3. (Опционально) VS Build Tools — если понадобятся native wheels.

### Шаг 2 — Восстановить проект

```powershell
# Распаковать/скопировать voxbridge, например:
cd "D:\Projects\voxbridge"
git status   # убедиться что репо целое
```

Восстановить `voice-matching-service/pretrained_models/spkrec-ecapa-voxceleb/` с бэкапа.

### Шаг 3 — Зависимости

```powershell
# Frontend
npm install

# Backend
cd voice-matching-service
python -m venv .venv
.\.venv\Scripts\activate
.\scripts\install-deps.ps1
```

### Шаг 4 — Запуск

```powershell
# Терминал 1
cd voice-matching-service
.\scripts\run-server.ps1

# Терминал 2
cd ..   # корень voxbridge
npm run dev
```

Проверка: http://localhost:8000/health и http://localhost:3000/admin/ai-voice-matching

### Шаг 5 — Cursor Agent

1. **File → Open Folder** → корень `voxbridge`.
2. Прочитать агенту: `@docs/ПРОГРЕСС_ПРОЕКТА.md` или `@AGENTS.md`.
3. Правила проекта: `AGENTS.md` (корень), при необходимости `.cursor/rules/`.
4. Новый чат Agent — описать задачу со ссылкой на `docs/ПЛАН_ДАЛЬШЕ.md`.

**Совет:** в первом сообщении после переустановки написать:  
«Проект VoxBridge, voice matching на FastAPI :8000, читай docs/ПРОГРЕСС_ПРОЕКТА.md».

### Шаг 6 — Git remote (если был)

```powershell
git remote -v
git pull
```

Коммиты делать только по явной просьбе (правило пользователя).
