# VoxBridge — Руководство пользователя

> Этот документ — для продюсеров и вокалистов, использующих платформу.
> Последнее обновление: 28 июня 2026.

---

## Для продюсеров

### Как найти вокалиста

1. Перейдите на страницу поиска.
2. Загрузите аудио-референс — это голос или трек, звучание которого вы хотите найти (например, демо с AI-вокалом или просто пример того, как должен звучать результат).
3. При желании уточните стиль — переключатель "Voice Style" (Any / Singing / Rap) помогает платформе точнее взвесить совпадение под нужный жанр.
4. Платформа покажет список вокалистов, ранжированный по акустическому сходству — насколько голос похож на ваш референс по тембру, высоте и манере.

### Как читать результаты поиска

- **Процент совпадения** — общая оценка похожести голоса. Это не гарантия "идеального" результата, а ориентир, с кого начать.
- **Уровень уверенности** (Very strong / Good / Partial / Weak match) — показывает, насколько надёжна сама оценка. При наведении на бейдж есть короткое объяснение.
- **Раскладка по признакам** (тембр, высота, идентичность голоса и т.д.) — показывает, в чём конкретно вокалист похож, а в чём отличается.

### Как оформить заказ

1. Откройте профиль понравившегося вокалиста.
2. Нажмите "Request Vocalist" — отправится запрос с описанием проекта.
3. После того как вокалист примет запрос, откроется совместное рабочее пространство — там идёт вся дальнейшая переписка, обмен файлами и статус работы.

### Статусы заказа

| Статус | Что значит |
|---|---|
| In progress | Работа началась |
| Preview pending | Вокалист готовит черновой вариант |
| Revision requested | Вы запросили правки |
| Preview approved | Черновик одобрен |
| Delivery ready | Финальный файл готов к выдаче |
| Completed | Заказ завершён |

### Если что-то пошло не так

Если вокалист долго не отвечает, не выполняет договорённости, или вы видите что-то подозрительное в профиле — используйте кнопку обратной связи/жалобы в рабочем пространстве или профиле. Опишите ситуацию конкретно — это передаётся администрации платформы для рассмотрения.

**Важно:** на данный момент платформа не обрабатывает оплату напрямую (функция оплаты в разработке) — все денежные договорённости с вокалистом вы согласовываете самостоятельно. Будьте внимательны при работе с новыми, непроверенными контактами.

## Для вокалистов

### Как создать профиль

1. После регистрации с ролью "Vocalist" откроется анкета (онбординг).
2. Заполните: жанры, в которых вы работаете, языки, голосовой диапазон, характер голоса (тёплый/яркий/глубокий и т.д.), оборудование для записи.
3. Загрузите хотя бы одно демо — без демо профиль не будет полноценно участвовать в поиске.

### Как получать заказы

Когда продюсер находит вас через поиск и отправляет запрос — вы увидите его в разделе запросов. У вас есть возможность принять или отклонить запрос.

- **Принять** — запрос превращается в заказ, открывается совместное рабочее пространство.
- **Отклонить** — запрос закрывается, продюсер не получает уведомление о причине (если хотите объясниться — это можно сделать до отклонения через переписку, если она была).

### Как работать над заказом

Загружайте черновики и финальные файлы через рабочее пространство. Продюсер может запросить правки (Revision requested) — это нормальная часть процесса, не повод для тревоги.

### Если что-то пошло не так

Если продюсер ведёт себя недопустимо, просит то, что не было оговорено изначально, или вы столкнулись с другой проблемой — используйте кнопку обратной связи/жалобы. Опишите ситуацию конкретно.

**Важно:** оплата пока не проходит через платформу напрямую — будьте внимательны при согласовании денежных условий с продюсером, особенно с новыми контактами.

## Общие правила для всех пользователей

- Указывайте достоверную информацию в профиле — фальшивые данные о голосе, опыте или личности являются нарушением и могут привести к блокировке аккаунта.
- Общение должно оставаться в рамках уважительного профессионального диалога.
- Любые споры, которые не получается решить напрямую между собой — обращайтесь к администрации платформы через функцию жалобы/обратной связи. Решения администрации основаны на внутренних правилах платформы.
