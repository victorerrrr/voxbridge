# Прогресс проекта VoxBridge

Документ для восстановления работы после переустановки Windows (май 2026).

---

## Что такое VoxBridge

**VoxBridge** — MVP маркетплейса для **продюсеров** и **вокалистов** в музыке.

Идея:
- Продюсер загружает **AI-вокал** (или описывает желаемый голос).
- Система показывает **ранжированный список** подходящих вокалистов.
- Можно сравнить AI vs реальный голос и оформить **заказ** → совместная **workspace**.

На этапе MVP:
- Основной фронтенд: Next.js, mock-данные, **localStorage** (без Supabase, пока пользователь явно не попросит).
- **Реальный AI voice matching** реализован как **отдельный Python-сервис** и подключён к **Admin AI Lab** (`/admin/ai-voice-matching`).
- Публичный producer flow (`/search` → `/results`) по-прежнему может использовать mock-matching; эталон «живого» AI — админ-лаборатория.

Дизайн: тёмная тема, modern music / AI SaaS.

## Что сделано (по фазам)

### Фаза A — MVP маркетплейс (Next.js)

- Лендинг `/`, fake auth, роли producer / vocalist.
- Producer: `/search` → upload context → `/results` → compare / profile → order → `/workspace/[orderId]`.
- Vocalist: onboarding, tags, demos, requests, shared workspace.
- Dashboard, home feed, mock matching (`lib/matching.ts`).
- Client-store без `useSyncExternalStore` (паттерн subscribe + hooks).
- Документация для агентов: `AGENTS.md`, `PROJECT_MEMO.md`.

### Фаза B — Voice Matching Service (Python)

- Отдельная папка `voice-matching-service/`:
  - `POST /voice-match` — multipart: `ai_vocal` + несколько `demos`.
  - `GET /health` → `{ "status": "ok" }`.
- **ECAPA-TDNN** embeddings, cosine similarity, сортировка по сходству.
- **Декодирование аудио**: torchaudio/torchcodec → soundfile → pydub/ffmpeg → librosa (fallback chain).
- **Обрезка 10 с** сразу после decode (до Demucs/ECAPA).
- **Demucs** (`htdemucs`, CPU): только на **AI vocal**; демо — trimmed mix (быстрее).
- **Chunk averaging**: 5 окон × 2 с, RMS-weighted ECAPA cosine → `speaker_score`.
- **Scoring v4.1 / v4.2**:
  - Веса: speaker 34%, timbre 28%, pitch 33%, quality 5%.
  - Vocal-type penalty (range band, male/female), rank penalty −8, alignment bonus.
  - Cross-demo stretch (лучший ~82–88%, худший ~22–35%), rank boost, caps (макс. 88/95/99, никогда 100).
- **Gender-priority ranking**: `final_ranking_score`, hard partition (female AI → female demos выше male).
- **Male prototype** `real_voice_1.wav`: timbre/pitch similarity ≥ 0.75 → `high_pitched_male`.
- **`MANUAL_DEMO_GENDER`**: ручной пол по basename (см. ниже).
- **`_force_demote_real_voice_1`**: `real_voice_1.wav` **никогда** не #1, всегда внизу списка.
- **Таймаут 30 с**: partial response `{ results, partial: true }` вместо падения.
- **Fallback encoder** (MFCC), если ECAPA не загрузился.
- **SpeechBrain без k2**: lazy stubs (`k2_fsa`, `huggingface.wordemb`), патч `LazyModule.ensure_module`.
- Скрипты: `scripts/install-deps.ps1`, `scripts/run-server.ps1`, `run-server.sh`.
- Подробный `voice-matching-service/README.md`.

### Фаза C — Admin AI Lab (Next.js)

- Страница `/admin/ai-voice-matching`.
- Компонент `components/admin/ai-voice-matching-lab.tsx`.
- Логика API и отображения: `lib/admin-ai-voice-matching.ts`:
  - `fetch` на `NEXT_PUBLIC_VOICE_MATCH_API_URL` (default `http://localhost:8000`).
  - Маппинг полей API → UI (similarity, breakdown, vocal types, feature tags).
  - **Русские подписи** типов голоса, причин, секций сравнения.
  - **Feature tags** (match / mismatch) для лаборатории.
  - Display caps: `MAX_DISPLAY_MATCH_PERCENT`, vocal mismatch cap 49%.
  - Клиентская демоция `real_voice_1` (дублирует/дополняет backend rule).
- Хук `hooks/use-lab-audio-playback.ts` — воспроизведение демо в лабе.

### Фаза D — Фиксы окружения и интеграции (сессии агентов)

| Проблема | Решение |
|----------|---------|
| pip «Missing dependencies for SOCKS support» | `scripts/install-deps.ps1`, сброс proxy в pip и env, `requests[socks]` / PySocks |
| VPN / `ALL_PROXY=socks4://127.0.0.1` ломает Hugging Face | Очистка proxy в `main.py`, `run-server.ps1`, `HTTPX_TRUST_ENV`, neutralize `getproxies()` |
| CORS «Failed to fetch» из AI Lab | CORSMiddleware: localhost/127.0.0.1 порты 3000–3002, methods/headers `*`, host `0.0.0.0` |
| WinError 1314 (symlink) при SpeechBrain | Обычный venv без admin; модель в `pretrained_models/` (копии, не symlink) |
| Дубликаты uvicorn на :8000 | Один процесс; убить stale python перед стартом |
| MP3 decode | torchcodec + ffmpeg PATH, pydub fallback |
| Долгие запросы | 10 s trim, Demucs только AI, partial при 30 s |
| Неверный пол у демо (MIDI ~64 → female) | `MANUAL_DEMO_GENDER`, male prototype, hard gender partition |
| UI на английском в лабе | Русификация labels, reasons, vocal type display |

## Как запустить после переустановки Windows

### 1. Системные зависимости

- **Node.js** LTS (для Next.js).
- **Python 3.10+** (3.11–3.12 предпочтительнее; 3.14 может работать, но менее предсказуемо).
- **ffmpeg** в `PATH` (full/shared build для torchcodec/pydub): https://www.gyan.dev/ffmpeg/builds/
- **Git** (репозиторий уже есть).

### 2. Frontend

```powershell
cd "c:\Users\_r3drum\Desktop\all\Новая папка\voxbridge"
npm install
npm run dev
# http://localhost:3000
```

Admin AI Lab: http://localhost:3000/admin/ai-voice-matching

### 3. Voice Matching Service

```powershell
cd voice-matching-service
python -m venv .venv
.\.venv\Scripts\activate

# Первый раз или после переустановки ОС:
.\scripts\install-deps.ps1

# Запуск (очищает proxy):
.\scripts\run-server.ps1
```

Или вручную (после очистки proxy):

```powershell
$env:HTTP_PROXY=""; $env:HTTPS_PROXY=""; $env:ALL_PROXY=""
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Проверка:

```powershell
curl http://localhost:8000/health
```

**Важно:** скопируйте папку `voice-matching-service/pretrained_models/spkrec-ecapa-voxceleb/` с бэкапа — иначе первый запуск снова скачает модель из интернета.

### 4. Порядок запуска

1. Python backend (:8000)
2. `npm run dev` (:3000)
3. AI Lab → загрузить AI vocal + demos → **Run Matching**

## Известные проблемы и обходы

### SOCKS / proxy (pip и Hugging Face)

**Симптом:** `Missing dependencies for SOCKS support`, ошибки httpx при скачивании модели.

**Обход:**
1. `voice-matching-service\scripts\install-deps.ps1`
2. Отключить VPN/прокси-клиент или очистить переменные пользователя Windows: `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY`
3. `python -m pip config unset global.proxy` (и `user.proxy`)

### WinError 1314 (symlink)

**Симптом:** SpeechBrain не может создать symlink при загрузке чекпоинта.

**Обход:** venv **без** «Запуск от имени администратора»; держать веса в `pretrained_models/` как обычные файлы (уже в git status как untracked — **сохранить при бэкапе**).

### Порт 8000 занят

**Симптом:** uvicorn не стартует / старый процесс отвечает устаревшим кодом.

**Обход (PowerShell):**

```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue }
```

Запускать **один** uvicorn.

### CORS / Failed to fetch

- Backend на `0.0.0.0:8000`, origins 3000–3002 в middleware.
- Origin браузера (например `http://localhost:3000`) должен быть в списке.
- `/health` OK, но POST падает — проверить, что не mixed content и URL в `NEXT_PUBLIC_VOICE_MATCH_API_URL` совпадает.

### Partial results

При 30 s+ или многих демо API вернёт `partial: true` — часть демо без scores; это ожидаемо на CPU.

### Дубликат `pretrained_models/` в корне репо

В git status может быть и `voxbridge/pretrained_models/`, и `voice-matching-service/pretrained_models/`. Рабочий путь для сервиса — **`voice-matching-service/pretrained_models/`**.

## MANUAL_DEMO_GENDER и правила real_voice_1

### `MANUAL_DEMO_GENDER` (Python, `main.py`)

Словарь basename → `"male"` | `"female"`. Используется для **ранжирования**, не перезаписывает `detected_vocal_type` в ответе.

```python
MANUAL_DEMO_GENDER: dict[str, str] = {
    "real_voice_1.wav": "male",
}
```

| Поле API | Смысл |
|----------|--------|
| `detected_vocal_type` | Автоклассификатор (multi-feature) |
| `manual_gender` | Значение из map или `null` |
| `final_vocal_type` | `manual_gender` ?? `detected_vocal_type` — для ranking и `vocal_type_match` |

Демо с mismatch получают reason: `demoted due to vocal type mismatch`.

### Male prototype (`real_voice_1.wav`)

- Эталон мужского тембра/высоты для запроса.
- Другие демо с cosine ≥ **0.75** по вектору [pitch, MFCC×13, centroid] → `high_pitched_male`, `final_vocal_type` = **male**.
- При **female AI** и наличии female demo — male/high-pitched male **не могут** быть index 0 (hard gender partition).

### Force demote `real_voice_1.wav`

**Отдельное правило:** файл с basename `real_voice_1.wav` **никогда** не остаётся #1 — переносится в **конец** списка, флаг `force_demoted_real_voice_1: true`. Дублируется на фронте в `lib/admin-ai-voice-matching.ts` для UI.
